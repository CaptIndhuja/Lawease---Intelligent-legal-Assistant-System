# Lawease – Intelligent Legal Assistant System

## Overview
Lawease is an AI-powered legal assistant system designed to simplify legal document analysis and query handling.  
It enables users to upload and process PDF documents efficiently using intelligent AI-based features.  
The system provides fast, accessible, and user-friendly legal assistance through an interactive platform.

## Features
- AI-based legal assistance
- PDF document processing
- FastAPI backend
- Frontend user interface
- Document upload support
- Legal query handling

## Technologies Used
### Backend
- Python
- FastAPI
- Uvicorn

### Frontend
- React
- Node.js

## Installation

### Backend Setup
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```

###Frontend Setup

```
cd frontend
npm install
npm run dev
```
