# Lawease – Intelligent Legal Assistant System

Lawease is an AI-powered legal assistant system designed to simplify legal document analysis and intelligent query handling.  
It enables users to upload and process PDF documents efficiently using advanced AI and NLP technologies.  
The system provides fast, accessible, and user-friendly legal assistance through an interactive web platform.

---

## Features
- AI-based legal assistance
- Legal document understanding
- PDF document upload and processing
- Intelligent query handling
- Interactive frontend interface
- Fast and scalable backend services

## Installation

### Backend Setup
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```

###Frontend Setup

```
cd frontend
npm install
npm run dev
```
